# 重生之我在宿舍当奶娃

[在线试玩与分享](https://kevin20322411-creator.github.io/naiwa-dorm/) · [GitHub 源码](https://github.com/kevin20322411-creator/naiwa-dorm)

一个面向大学生的手机网页小游戏。20 种天赋中随机展示六项，跨批选择两项入学；每天经历三餐与五个校园场景，可以连续过日子，也可以带着当天称号收工。包含 85 条校园事件资料（保留旧规则内容）、31 种三餐食物与 37 项结局成就。

界面使用白灰底色、简短操作文案和响应式卡片。未解锁成就仅展示锁图标，今日回顾默认折叠；事件正文、选择效果与失败风险保留。

## 天赋与开局

- 换一批自动保留已经选中的天赋，并排除上一批候选；已选栏右上角的 × 可取消。最多选两项。
- 新局有 20% 概率得到一次性开局加成，随机为一个尚有空间的属性 +12。包括电量、饭钱、人缘、学业、健康、心情；加成一定实际生效。菜单、加成和事件时间均由种子确定，刷新不会重抽。

## 生存规则

- 电量归零：触发“奶娃强制关机”，结束本局。
- 学业归零：触发游戏中的“学业劝退通知”，结束本局。
- 健康初始 80、心情初始 65，上限均为 100。健康归零会请假休养并结束本局；心情低落不会直接失败，会影响休息恢复。
- 早餐、午餐、晚餐各从食物库抽四种，再提供“不吃”选项；每餐至少一项免费。食物影响电量、健康、心情和预算，普通互动也会影响心情。三餐之外的事件会在合适时段内随机出现，具体分钟每天变化。
- 饭钱不足：无法选择超出余额的消费，仍有互助、兼职等路线；每餐始终保留免费选择。
- 赚钱事件在饭钱少于 20 时提高权重，少于 8 时进一步提高；次日饭钱少于 10 时，上午会提供实际赚钱路线。可选择接受或放弃，不直接发钱。
- 每天结算后可以继续下一天：电量通常最多恢复 12，心情高于等于 75 时最多 16，低于 25 时最多 8；健康最多 +2、心情最多 +4、饭钱扣除最多 4。新课压力扣除学业 `min(30, 8 + 当前天数 × 2)`。结算页列出实际变化和劝退风险。
- 优先避开最近 24 个已见事件；资源危机等必要的补救事件例外。刷新不重新抽事件，也不重新计算概率结果。
- 每日称号和失败结局都可收入图鉴。旧版图鉴继续沿用，旧版单日存档保留在原键位，新规则使用独立存档。
- 同一天满足多项成就时全部收录，不会被当天展示的主称号覆盖。
- 新成就通过弹窗展示，一次解锁多个会一起列出；含 3 项隐藏、3 项高难成就，未解锁时不显示名称或条件。
- 同一局完整度过 3 天获得新生适应证，7 天获得“一周仍在校”。完整度过至少 14 天，且当日结算时学业达到 80，获得奶士学位；30 天后的同一评定条件可获得宿舍荣誉奶士。未达标可继续，之后满足条件再领；进入第 14 天时失败不算完成 14 天。获得后继续玩或后续失败，不撤回已获得的学位。

## 存档兼容

新局使用版本 5。版本 2、3、4 的历史选择仍使用对应规则重演；继续已有在读存档时记录一次生活规则升级，加入三餐、健康和心情，保留已经发生的经历和成就。全部版本沿用同一存档入口，不会自动清除旧局。

存档通过对应版本的规则重演验证；不要直接修改已经发布版本的事件池或事件文案，否则会破坏旧存档校验。后续扩充应新增内容版本。

## 本地运行

项目不需要安装依赖。使用任意静态网页服务器托管 `dist/`，或运行：

```sh
node preview.cjs
```

然后打开终端显示的本地地址。支持手机和电脑。普通选择保持安静；首次达成重要里程碑或失败时，复用贪吃奶娃的鼓励短语音和笑声，降低音量并限制时长，同一时间仅播放一段。音效首次默认开启，右上角可静音，并保留已有的静音设置。进度与结局图鉴保存在当前浏览器，清理浏览器数据会丢失。使用正式链接或本地服务器，可获得稳定的进度保存和图片导出体验。

也可生成一个图片、声音与代码全部内嵌的单文件，方便直接在浏览器试玩：

```sh
node export.cjs 体验版.html
```

## 文件

- `dist/index.html`：页面入口
- `dist/styles.css`：响应式界面
- `dist/engine.js`：基础天赋与最初八个事件
- `dist/events.js`：额外随机事件与条件事件
- `dist/campus.js`：版本 3 新增事件、天赋与主题称号
- `dist/economy.js`：新增早间赚钱机会
- `dist/challenges.js`：隐藏与高难成就
- `dist/life.js`：三餐菜单、健康心情初值与随机时间
- `dist/survival.js`：抽取、跨天、失败、结局和存档验证
- `dist/app.js`：交互、存档、图鉴和结局卡导出
- `dist/assets/`：从用户之前的奶娃项目复用的图片与音频

## 规则验证

```sh
node tests/survival.cjs
node tests/compatibility.cjs
node tests/ui-state.cjs
node tests/draft-economy.cjs
node tests/life.cjs
node tests/challenges.cjs
```

模拟 6000 局、每局最多 30 天，检查当前规则可用事件、跨天继续、归零终止、消费限制、近期事件回避、固定概率结果、存档恢复和篡改拒绝。冻结样本验证旧版本兼容；专项验证三餐、健康失败、开局加成、赚钱机会、学位门槛和全部隐藏/高难成就可达。界面控制测试包含跨批选择、成就弹框和普通选择静音，不替代真实浏览器视觉检查。
